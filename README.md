# js-multiplier-hands-on-rot-n8n

**Joule Studio CS&D Multiplier Workshop — n8n Low-Code Path**

A self-contained static HTML site for the Invoice Exception Agent hands-on session.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Landing page — workshop overview, requirements, prerequisites, scenario cards, CTA |
| `tutorial.html` | 37-step click-by-click tutorial (6 exercises) with screenshots |
| `scenarios.html` | 7 sample n8n scenario prompts with business use cases and copy buttons |

## Content Sources

- **Tutorial content** — _"How to create Invoice Exception Agent with n8n workflow"_ (Deval's Team, Oct 2026, 37 steps)
- **Scenario prompts** — _"Sample Scenario Prompts for n8n"_ (Doc 2, 7 scenarios)

## Images

Screenshots in `images/` are taken directly from the Joule Studio int landscape and correspond 1-to-1 with the tutorial steps.

## Running Locally

Open `index.html` directly in Chrome — no build step required.
