Sample Scenario Prompts for n8n

Seven ready-to-use prompts covering the most common n8n workflow patterns in Joule Studio. Copy a prompt, paste it in Joule Studio, and start building.

1
Scenario 1

Workflow with SAP Task Center Node

Business Use Case

When an external system submits a request via webhook, the workflow automatically creates a personal notification in SAP Task Center for the responsible person — with the request title pre-populated from the incoming data. Example: a contract review request arrives from an external portal and instantly appears as a Task Center action item for the contract owner, with no manual entry.

Technical Prompt Fast Track
Create a workflow with an SAP Task Center node that always sends a notification to <give test email id>. Use a webhook trigger. The webhook trigger provides the title the notification will have. Fast Track. No questions asked.
2
Scenario 2

Workflow with AI Core Node

Business Use Case

A business user submits a piece of text — a customer review, a survey response, or an employee comment — via API call. The workflow sends it to SAP AI Core, classifies the sentiment as positive, negative, or neutral, and returns the result immediately. The support or HR team gets an instant signal without reading every submission manually.

Technical Prompt Fast Track
Please create a workflow. The workflow should have a webhook to start the workflow and take input on which via AI core, it can do sentiment analysis and respond back with the sentiment from positive, negative, neutral. Fast Track. Start with intent-analysis.
3
Scenario 3

Workflow calling existing LoB Agent (A2A)

Business Use Case

A procurement coordinator triggers a workflow to query the Sourcing Event Agent — an existing SAP LoB agent — and get back information about its capabilities or active sourcing events. The result is returned directly, letting the team understand what the agent can do without logging into another system.

Technical Prompt
Create a workflow that calls the Sourcing Event Agent with the SAP Agent Node. It should call it with the query "What's your functionality" and return the result. The workflow should have a webhook.
4
Scenario 4

Workflow calling existing Custom Agent (A2A)

Business Use Case

A finance analyst submits a base figure via an API call. The workflow fetches a second value from a separately deployed agent and returns the combined total — reusing a specialist agent already in the system rather than rebuilding its logic. The workflow only owns what is new.

Technical Prompt Fast Track
I need a workflow that adds two numbers. One number should be passed as input to the workflow. The other number should be generated by the number generator agent already in the system called "Random Number Agent". Fast track. Make no mistakes.
5
Scenario 5

Workflow calling Custom Agent (calls MCP) in same solution (A2A)

Business Use Case

An operations planner submits a list of order quantities from different customers. The workflow calls a same-solution intelligent agent that calculates the highest common factor across all values — identifying the largest batch size that evenly satisfies every order. The agent and workflow are packaged and deployed together as one solution.

Technical Prompt
Create a workflow that starts with a webhook. The webhook takes an array of numbers. The workflow then calls a custom agent in the solution to analyze this array and get the highest common factor of the numbers. The workflow should finally respond with the output of the agent.
6
Scenario 6

Custom Agent calling existing workflow

Business Use Case

A Joule assistant is asked whether a backend processing workflow is live and reachable. The agent calls the already-deployed workflow and confirms it responded — giving the ops team an instant health check through conversation, without navigating to the workflow dashboard. In the data variant, the agent calls a binary-output workflow and communicates the pass/fail result in plain language.

Technical Prompt (Without Data)
Prereq — deployed "hello world" workflow with webhook trigger. Create an agent that calls my deployed hello world n8n workflow. Agent should say "Yey" if it was able to call the workflow.
Technical Prompt (With Data)
Create an agent that calls my deployed n8n workflow which is a 0/1 outputter.
7
Scenario 7

Custom Agent calling workflow in same solution

Business Use Case

When asked to make a fair split assignment, a Joule assistant calls a same-solution workflow that generates a random integer, then uses the even or odd result to place an item — an employee, a task, a ticket — into one of two groups. The assistant responds with the number and the outcome. The workflow and agent are built and deployed together as a single unit.

Technical Prompt
Create an n8n workflow that generates a random integer. Then create an agent that calls this workflow, receives the generated number, and determines whether it is even or odd, responding with the number and its result.
