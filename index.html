About This Workshop

Build a production-ready AI workflow in Joule Studio using the n8n low-code path — no CLI required

In this hands-on session you will use Joule Studio to build a complete Invoice Exception Agent from a single natural-language prompt. Joule Studio’s intent-based development (IBD) flow turns your description into a fully wired n8n workflow — with a webhook trigger, SAP S/4HANA connectivity, an embedded AI agent, SAP Task Center human-in-the-loop approval, and automated invoice release.

What You Will Build

A sample set of requirements illustrating the invoice exception management lifecycle — Joule Studio generates requirements dynamically, so yours may vary slightly

Representative Sample
These requirements are indicative. Joule Studio derives requirements from your intent at runtime, so the exact wording and number of requirements may differ from what you see here.
🔗
R1 — Webhook Trigger from Joule Agent

The workflow is triggered by a Joule Agent from SAP Joule chat via a webhook.

📄
R2 — Read All Blocked Supplier Invoices from S/4HANA

Fetches all blocked supplier invoices from SAP S/4HANA Cloud using the SAP MCP Client.

🤖
R3 — AI-Powered Block Reason Analysis per Invoice

A SAP Agent analyses each invoice to identify the block reason across Purchase Order, Goods Receipt, and Supplier Contract.

✅
R4 — AP Clerk Approval via SAP Task Center

The agent’s findings are presented to the AP Clerk in SAP Task Center using SAP Human-in-the-Loop.

🚀
R5 — Invoice Release in S/4HANA on Approval

If the AP Clerk approves, the invoice is released in S/4HANA Cloud via the SAP MCP Client.

💬
R6 — Summary Response Returned to Joule Agent

A summary of the outcome is returned to the Joule Agent for display in SAP Joule chat.
